Política de privacidade

Este site mostra a minha carteira e os meus resultados. Não vende nada diretamente.

Que dados este site recolhe

Eu não recolho dados pessoais. O site não tem formulários, não pede registo, não usa estatísticas nem publicidade e não guarda cookies.

Vídeos do Instagram e do YouTube

Os vídeos estão alojados no Instagram (Meta) e no YouTube (Google). Os vídeos aparecem na página Verificação e quando abres um episódio da série, no modo de privacidade reforçada do YouTube. A partir daí, esses serviços podem recolher dados e guardar cookies, segundo as políticas de privacidade deles.

Alojamento

O site está alojado no GitHub Pages (GitHub, Inc.). Como qualquer servidor, o GitHub regista o endereço IP de quem visita, por razões de segurança, durante o tempo definido na declaração de privacidade do GitHub. Eu não tenho acesso a esses registos. O GitHub é uma empresa dos EUA; a transferência está coberta pelo Quadro de Privacidade de Dados UE-EUA.

Ligações para outros sites

As ligações para a Bybit, a Bitget, o Instagram e o YouTube abrem sites de terceiros, com as suas próprias regras de privacidade.

Responsável e os teus direitos

O responsável pelo site é Hugo Almeida. Podes pedir informação, correção ou apagamento de dados e opor-te a qualquer tratamento. Também podes apresentar queixa à Comissão Nacional de Proteção de Dados (cnpd.pt).

Para qualquer questão sobre privacidade, fala comigo no Instagram @esferaarmilar.pt.
